# Expense Tracker

Track income and expenses with categories, visual summaries, and data export.

## Features

- Add income/expense transactions
- Categories with color coding
- Balance summary (income, expenses, net)
- Transaction history with filters
- CSS-based bar chart visualization
- Search transactions
- JSON export/import
- Clear all data
- Local storage persistence

## Technologies

- HTML5
- CSS3 (Grid, custom properties)
- Vanilla JavaScript
- localStorage

## How to Run

Open `index.html` in a web browser.

## Data Storage

All transactions stored in browser localStorage.
Export to JSON for backup.
