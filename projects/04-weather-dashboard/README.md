# Weather Dashboard

Real-time weather information using Open-Meteo free API.

## Features

- City/location search (geocoding)
- Current weather conditions
- 5-day forecast
- Temperature, humidity, wind speed
- Weather icons and descriptions
- Geolocation support
- Loading states and error handling
- Dark/light theme

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Open-Meteo API (free, no key required)
- Geocoding API

## How to Run

Open `index.html` in a web browser.

## API Usage

Uses Open-Meteo's free public API:
- No API key required
- No rate limits for reasonable use
- Geocoding via Open-Meteo's geocoding endpoint

## Data Storage

- Recent searches cached in localStorage
- Theme preference stored locally
