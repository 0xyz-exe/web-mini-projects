# Interactive Portfolio

A modern, responsive developer portfolio showcasing skills, projects, and experience.

## Features

- Responsive hero section with call-to-action
- Project showcase with cards
- Skills categorization
- Experience timeline
- Contact form
- Dark/light theme toggle
- Smooth scrolling navigation
- Mobile-responsive design

## Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript

## How to Run

Open `index.html` in a web browser.

## Usage

1. Navigate through sections using the top menu
2. Toggle dark/light theme using the moon/sun button
3. Fill out the contact form (demo mode - alerts shown)
4. View on mobile for responsive experience

## Data Storage

- Theme preference stored in localStorage

## Customization

Edit the content in `index.html` to personalize:
- Name and title
- Projects
- Skills
- Experience timeline
- Contact information
