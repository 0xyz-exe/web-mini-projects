# GitHub Profile Explorer

Search GitHub users and view their profiles, repositories, and stats using the public GitHub API.

## Features

- User search by username
- Profile display (avatar, bio, stats)
- Repository list (name, description, language, stars, forks)
- 12 most recently updated repos
- Links to GitHub profiles and repos
- Error handling (404, rate limits, network failures)
- Loading states
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- GitHub REST API v3

## How to Run

Open `index.html` in a web browser.

## API Usage

Uses GitHub's public API. No authentication required.
Rate limit: 60 requests/hour per IP for unauthenticated requests.
