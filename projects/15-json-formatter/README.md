# JSON Formatter & Validator

Validate, format, and minify JSON with syntax error feedback.

## Features

- JSON syntax validation
- Pretty formatting (2-space indent)
- Minification
- Syntax error messages
- Copy to clipboard
- Sample JSON included
- Real-time status indicator
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid)
- Vanilla JavaScript
- JSON.parse (safe parsing)

## How to Run

Open `index.html` in a web browser.

## Security

Uses `JSON.parse()` for safe parsing. No eval or code execution.
