# Typing Speed Test

Measure WPM, accuracy, and typing performance with real-time feedback.

## Features

- Real-time WPM calculation
- Accuracy tracking
- Error counting
- Live character highlighting (correct/incorrect/current)
- Multiple text samples
- Elapsed time display
- Results summary
- Restart functionality
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript

## How to Run

Open `index.html` in a web browser.

## Usage

1. Click "Start Test"
2. Type the displayed text
3. See live stats update
4. Review results when complete
