# Notes Application

Full-featured notes app with creation, editing, search, pinning, and data management.

## Features

- Create, edit, delete notes
- Pin important notes
- Search notes (title and content)
- Filter by all/pinned
- JSON export/import
- Auto-save to localStorage
- Responsive grid layout
- Date tracking (created/updated)
- Empty state handling
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- localStorage

## How to Run

Open `index.html` in a web browser.

## Data Storage

All notes stored in browser localStorage.
Export to JSON for backup or transfer.
