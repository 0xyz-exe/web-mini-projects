# Calculator Suite

Functional calculator with keyboard support and error handling.

## Features

- Basic arithmetic operations (+, −, ×, ÷)
- Decimal support
- Percentage calculation
- Clear and backspace
- Keyboard support (numbers, operators, Enter, Escape)
- Error handling (division by zero)
- Floating-point precision handling
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid)
- Vanilla JavaScript

## How to Run

Open `index.html` in a web browser.

## Keyboard Shortcuts

- Numbers: 0-9
- Operators: +, -, *, /
- Decimal: .
- Equals: Enter or =
- Clear: Escape
- Backspace: Backspace
- Percent: %
