# Pomodoro Timer

Productivity timer with work/break cycles, notifications, and session tracking.

## Features

- Work/break session modes
- Start, pause, reset controls
- Configurable durations (work, short break, long break)
- Session counter (4 work sessions before long break)
- Browser notifications
- Completed sessions tracking
- Total time tracking
- Local storage persistence
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- Notifications API
- localStorage

## How to Run

Open `index.html` in a web browser.

## Permissions

Browser may request notification permission for alerts.
