# Markdown Editor

Live preview markdown editor with formatting shortcuts and download.

## Features

- Real-time live preview
- Formatting toolbar (bold, italic, headings, lists, code, links)
- Safe HTML rendering (escaped)
- Download as .md file
- Auto-save to localStorage
- Sample content included
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid)
- Vanilla JavaScript

## How to Run

Open `index.html` in a web browser.

## Security

User input is HTML-escaped before rendering. Markdown is parsed safely without eval or innerHTML injection.
