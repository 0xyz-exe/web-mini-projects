# Quiz Application

Interactive quiz with multiple-choice questions, timer, scoring, and answer review.

## Features

- 10 web development questions
- Multiple choice answers
- Progress bar indicator
- 10-minute countdown timer
- Instant scoring
- Detailed results with stats
- Answer review with correct/incorrect marking
- Restart functionality
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript

## How to Run

Open `index.html` in a web browser.

## Customization

Edit the `questions` array in `script.js` to add/modify questions.
