# Task Manager

Complete task management application with CRUD operations, filtering, and local persistence.

## Features

- Create, edit, delete tasks
- Mark tasks as complete
- Set priorities (low, medium, high)
- Due dates
- Search and filter (all/active/completed)
- Sort by date, priority, or title
- Clear completed tasks
- Local storage persistence
- Dark/light theme
- Task statistics

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- localStorage

## How to Run

Open `index.html` in a web browser.

## Data Storage

All tasks stored in browser localStorage. Data persists across sessions.
