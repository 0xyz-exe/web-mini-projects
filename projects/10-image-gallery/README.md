# Image Gallery

Responsive image gallery with local file upload, categories, search, and lightbox viewer.

## Features

- Local file upload (multiple)
- Category organization
- Search by name/category
- Category filter
- Lightbox modal viewer
- Keyboard navigation (arrow keys, escape)
- Delete images
- Responsive grid layout
- Lazy loading
- localStorage persistence
- Dark/light theme

## Technologies

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- FileReader API
- localStorage

## How to Run

Open `index.html` in a web browser.

## Privacy

Images stored locally in browser. No uploads to external servers.
Storage limited by browser localStorage (~5-10MB).
